# Student Portfolio & Academic Management Website

Responsive multi-page portfolio built with semantic HTML5, external CSS3 and vanilla JavaScript.

## Pages

- `index.html` — homepage and featured projects
- `about/index.html` — biography, education, aspirations, skills and interests
- `projects/index.html` — three sample project showcases
- `planner/index.html` — add, complete, delete and clear-completed tasks
- `contact/index.html` — contact form with client-side validation

## Run locally

Open `index.html` in a browser, or run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

The planner currently stores tasks in memory only. The contact form validates but does not transmit messages. 

See `website_docs.md` for the report and defence guide.
